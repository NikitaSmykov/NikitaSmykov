### Applied AI Engineer & Computational Researcher

I am an Applied AI Engineer specializing in neuroinformatics, AI-native biotechnology, and distributed systems. Currently, I am the founder of Polyphoros, where I lead the development of the Q.E.D. Engine—a deterministic *in silico* drug discovery pipeline. 

My core engineering philosophy centers on building *Zero-Hallucination AI*. I bridge localized LLMs, large-scale knowledge graphs, and formal mathematical verification (Lean 4) to eliminate probabilistic errors in critical systems.

### 📂 Independent R&D & Open-Source Portfolio
*Note: The core Q.E.D. Engine and its formal verification pipelines (Polyphoros) are strictly proprietary and closed-source. The repositories below are foundational open-source utilities, generic cheminformatics benchmarks, and data-engineering modules.*

**1. BioKG-ETL | Medical Knowledge Graph Processor**
*Tech Stack: `Neo4j`, `Python`, `Pandas`, `Cypher`*
An open-source data engineering pipeline designed to ingest, clean, and map generic biomedical datasets (e.g., standard PubMed abstracts) into a structured Neo4j graph database. Built to demonstrate high-throughput graph database management for biological entities.

**2. ChemML-Baselines | ADMET Benchmarking Suite**
*Tech Stack: `PyTorch`, `DeepChem`, `RDKit`, `Python`*
A benchmarking utility that trains standard Graph Neural Networks (GNNs) on public datasets (like MoleculeNet) to predict basic pharmacokinetic properties (ADMET). Serves as a baseline testing environment for evaluating predictive cheminformatics models.

**3. Lean4-Logic-Sandbox | Formal Methods in Python**
*Tech Stack: `Lean 4`, `Python`, `Z3 Solver`*
A collection of generic integration scripts bridging Python environments with the Lean 4 theorem prover. Used to test basic API calls, syntax translations, and simple automated reasoning tasks outside of proprietary biological contexts.

**4. HTVS-Orchestrator | High-Throughput Virtual Screening Pipeline**
*Tech Stack: `Python (Numba JIT)`, `ONNX Runtime`, `PyTorch`, `RDKit`*
Architected a high-performance batch-processing pipeline for *in silico* screening of large-scale chemical libraries. Implemented sub-millisecond SMILES parsing and molecular feature extraction utilizing Numba JIT and tensor-optimized computations deployed via ONNX Runtime.

**5. ChemSafe-Verifier | Formally Verified Toxicity Bounding**
*Tech Stack: `Lean 4`, `Python`, `Z3 Solver`, `Formal Methods`*
Engineered a mathematical verification layer for chemical property bounding. Utilized the Lean 4 theorem prover to formally guarantee that algorithmically generated molecular descriptors (e.g., Lipinski's Rule of 5 parameters) strictly adhere to predefined pharmacokinetic thresholds before downstream ML processing.

**6. PocketVision | 3D Protein Cavity Mapping AI**
*Tech Stack: `Python`, `PyTorch 3D`, `OpenCV`, `Biotite`*
Developed a 3D computer vision and spatial-planning algorithm intended for automated protein binding site identification. Analyzes volumetric structural data (PDB files) in real-time to generate coordinate trajectories and bounding boxes for molecular docking grids.

**7. BioMed-GraphRAG | Agentic Literature Extraction**
*Tech Stack: `LangGraph`, `Neo4j`, `HuggingFace`, `Python`*
Built an *in silico* agentic retrieval environment combining Local LLMs with GraphRAG. Maps massive unstructured biological datasets into Neo4j to simulate logical reasoning paths for generic biochemical interactions and target identification.

**8. OmicsCore | High-Throughput Multi-Omics ETL Architecture**
*Tech Stack: `Apache Kafka`, `PostgreSQL`, `Scanpy`, `Docker`*
Engineered a distributed, high-throughput ETL architecture in Python to ingest, denoise, and standardize continuous multi-terabyte multi-omics data streams (e.g., scRNA-seq) for downstream downstream ML inference.

**9. GeneNetwork-Emulator | AI-Accelerated Pathway Emulation**
*Tech Stack: `PyTorch`, `CellOracle`, `Neo4j`, `Lean 4`*
Engineered a foundational *in silico* emulation pipeline for mapping Gene Regulatory Networks (GRNs). Reconstructed basic cellular pathways into a directed multi-graph (Neo4j). Achieved fast execution of pathway perturbations using tensor-optimized computations in PyTorch.
